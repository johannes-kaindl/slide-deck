# Slide Deck — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning, doing, looking up and understanding are four different needs, so they get four kinds of pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first exported deck.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do, and where to get help.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Write a deck in a note, preview it, export it. |
| **[How-to: write your own theme](themes/THEMING-GUIDE.md)** | Task-oriented. A theme is one `.css` file — tokens, header directives, fonts, export fidelity. |
| **[Reference: slide layouts & syntax](layouts.md)** | Information-oriented. The twelve templates, the density modifiers, the layout and column directives, layout inference. ([Deutsch](layouts.de.md)) |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "content overflows", "Export failed", "No endpoint reachable". |
| **[Reference: sample decks](themes/demo-deck.md)** | Example-oriented. [`demo-deck.md`](themes/demo-deck.md) and [`traces-layouts-deck.md`](themes/traces-layouts-deck.md) are decks you can copy into a note; [`regression-deck.md`](themes/regression-deck.md) is the test deck behind the export checks. |

The [README](https://github.com/johannes-kaindl/slide-deck/blob/main/README.md) covers what the plugin does, how to install it, every setting and the frontmatter keys.
